Go to the **Project** app.

Find the project **`Atlas Implementation Sprint`** and open the task **`Prepare onboarding checklist`**.

Complete the workflow as follows:

1. Go to the **Sub-tasks** tab.
2. Add a new subtask named **`Draft kickoff agenda`**.
3. On that subtask, assign it to **Administrator**.
4. Make sure it ends up in **In Progress**.
5. Save the task.

**Rules:**
- Do not rename the parent task
- Do not create more than one subtask
- Do not edit any other task in the project
- Do not change the parent task deadline
