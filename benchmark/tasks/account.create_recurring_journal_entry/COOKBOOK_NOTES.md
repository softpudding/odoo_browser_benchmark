- Journal Entries (move_type='entry') are at `/odoo/accounting/entries` (action `account.action_move_journal_line`, `path='entries'`, context `default_move_type='entry'`). Different form from invoices: no Customer field, no Invoice Lines tab -- instead a `line_ids` one2many with explicit Account / Partner / Label / Debit / Credit columns.
- The Journal Items tab (aml_tab) has `groups="account.group_account_readonly"`. The base snapshot admin sometimes renders the form without this tab visible; seed should explicitly add admin to `account.group_account_readonly`, `account.group_account_invoice`, and `account.group_account_user` using `res.groups.user_ids` (NOT `users`).
- Journal-entry form header button is labeled **Post** (not Confirm). `invisible="hide_post_button or move_type != 'entry'"`. The `hide_post_button` compute hides the Post button when `auto_post != 'no' and date > today`, so if the task sets a future accounting date, `auto_post` must remain 'no' (default) to keep the Post button visible.
- The Journal Items `line_ids` list uses `section_and_note_text` widget on the `name` (Label) column. For non-section rows this renders a `<textarea>`, not `<input>`. Oracle cell filler must target `input, textarea` together.
- Account autocomplete items are formatted as "`<code> <name>`" (e.g. "612000 Rent"). Playwright `filter(has_text="Rent")` matches substrings, so "Rent" also matches "Cur**rent** Assets" (first CoA account). Exact matching must split the item text on whitespace and compare `parts[1]` to the account name, or match via case-insensitive endswith " <name>".
- `auto_post` field options: `no`, `at_date`, `monthly`, `quarterly`, `yearly`. Setting `monthly`+future date triggers `_copy_recurring_entries()` on post which duplicates the entry next period. Not used here (post button visibility conflict); instead we scheduled a chatter activity, which `check.py` asserts via `mail.activity` on `res_model='account.move'`.
- Generic CoA ships account "Rent" (code 6120, account_type='expense'), "Tax Paid" (code 1310, asset_current), but NO "Bank" account -- the default Bank journal auto-creates a liquidity account `asset_cash` named after the journal ("Bank"). Seed can rename that account's `name` for deterministic autocomplete.
