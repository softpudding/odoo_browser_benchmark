# Register a New Piece of Maintenance Equipment

Create a new equipment record in **Maintenance**.

1. Open the **Maintenance** app.
2. From the top menu, open **Equipments**.
3. Click **New** to start a new equipment record.
4. Set the equipment **Name** to `Dock Scanner DS-200`.
5. Set the **Equipment Category** to `Warehouse Gear` (pick the existing category).
6. Set the **Team** to `Bench Maintenance` (pick the existing maintenance team).
7. Open the **Product Information** tab and set the **Serial Number** to `DS-200-SN-1042`.
8. Save the record.

## Rules

- Use the exact equipment name, category, team, and serial number shown above.
- The `Warehouse Gear` category and `Bench Maintenance` team already exist — select them, do not create new ones.
- Do not modify or delete any existing equipment records.
- Leave the new equipment active (do not archive it).
