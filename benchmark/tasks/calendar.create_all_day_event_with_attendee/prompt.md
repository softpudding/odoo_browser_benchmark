# Create The All-Day Offsite Event

Create a new all-day calendar event.

1. Go to the **Calendar** app.
2. Create an event named `Operations Offsite`.
3. Mark it as **All Day**.
4. Set the date to `June 18, 2026`.
5. Set **Location** to `Mountain View Campus`.
6. Set the description to `Annual planning offsite for operations leads.` (on the **Options** tab).
7. Add `Marc Demo` as an attendee.
8. Save the event.

## Rules

- Create exactly one event with that title.
- Do not make it recurring.
- Do not add any attendee other than `Marc Demo`.
