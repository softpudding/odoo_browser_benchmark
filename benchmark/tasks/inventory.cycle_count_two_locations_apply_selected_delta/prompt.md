Open the **Inventory** app and go to **Physical Inventory**.

Find the two rows for product **`Bench Cycle Count Rotor`**. The product exists in two internal locations:

- `WH/Stock`
- `WH/Input`

Only adjust the row in location **`WH/Stock`**:

1. In the `WH/Stock` row, set **Counted Quantity** to **`12`**.
2. Click **Apply** for that row.

Leave the `WH/Input` row unchanged.

## Rules

- Only change the row for location `WH/Stock`
- Do not modify the `WH/Input` row
- Do not create a new quant line
- Do not use **Apply All**
