# Create The Supplier Company Record

Create a new company contact in **Contacts**.

1. Create a company named `North Coast Fabrication`.
2. Fill these fields:
   - **Street**: `1450 Harbor Rd`
   - **City**: `Tacoma`
   - **ZIP**: `98402`
   - **Email**: `ops@northcoastfab.com`
   - **Phone**: `+1 555 0182`
   - **Website**: `https://northcoastfab.com`
3. Add the `Supplier` tag.
4. Save the company.

## Rules

- Create a company, not an individual contact.
- Do not create any child contacts.
- Do not edit `North Coast Fabrication East`.
