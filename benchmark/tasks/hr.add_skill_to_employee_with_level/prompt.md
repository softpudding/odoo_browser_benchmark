Go to the **Employees** app.

Find the employee named **"Tech Tom"**.

Open his employee form and navigate to the **Skills** tab (in the Resume tab group, the lower Skills section).

Add a new skill entry with the following values:

1. Click **Pick a skill from the list** (or the "Add" / "+" button in the Skills table).
2. Set **Skill Type** to **"Programming Languages"**.
3. Set **Skill** to **"Python"**.
4. Set **Level** to **"Advanced"**.

Save the record (Save & Close the skill dialog, then save the employee form if needed).

**Rules:**
- Only modify the employee **"Tech Tom"**.
- Add the skill in the **Skills** section (not the Resume / experience section above).
- Skill Type must be **"Programming Languages"** (not "IT Skills" or any other).
- Do not change the employee's name, job position, or any other fields.
- Do not archive or delete the employee.
- Do not add any other skills.
