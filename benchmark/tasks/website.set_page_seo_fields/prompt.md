Open the seeded website page **`Bench SEO Page`** (URL `/bench-seo-page`) and set its SEO metadata using the **Promote** (Optimize SEO) dialog.

Steps:

1. From the **Website** app (`/odoo/website`), navigate to the page `/bench-seo-page` so the page is shown inside the website preview. You can either pick it from **Site > Pages** or type `/bench-seo-page` into the address bar of the preview.
2. While viewing the page, open the top-navbar **`Site`** menu. Under the *This Page* section, click **`Optimize SEO`** (also labelled "Promote"). This opens the **Optimize SEO** dialog.
3. In the dialog, set:
   - **Title** (meta title): `Bench SEO Meta Title`
   - **Description** (meta description): `Bench SEO meta description text.`
   - **Keywords**: add the following three keywords one at a time (press Enter after each, or click the add button):
     - `bench`
     - `seo`
     - `odoo`
4. Click **Save** to close the dialog and persist the SEO fields.

**Rules:**
- Do not rename the page or change its URL.
- Do not unpublish the page.
- Do not modify any other content on the page.
