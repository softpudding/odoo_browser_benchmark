Add a new top-level menu entry to the primary website that links to an existing page.

1. Open the Website app.
2. Open the Site menu and choose Menu Editor (the dialog that lets you add, edit, and reorder website menu entries).
3. Click `Add Menu Item` to create a new menu entry with:
   - `Name`: `Benchmark Contact`
   - `URL`: `/benchmark-contact`
4. Save the menu editor so the new menu entry is persisted.

Rules:
- Use the exact name `Benchmark Contact` and URL `/benchmark-contact`.
- The menu entry must be a child of the primary website's main menu (top-level entry alongside Home, Shop, etc.).
- The menu entry must belong to the primary website (website id 1), not shared across all websites.
- Do not delete or rename any other menu entries.
- Do not create extra menu entries or duplicate "Benchmark Contact".
- Do not create a new website page; the page `/benchmark-contact` already exists.
