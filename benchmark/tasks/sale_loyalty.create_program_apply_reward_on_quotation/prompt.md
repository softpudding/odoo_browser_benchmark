Go to the **Discount & Loyalty** configuration and create a code-based program with these exact values:

- **Program Name**: `Harbor 15% Quotation Reward`
- **Code**: `HARBOR15`
- **Reward**: `15%` discount on the whole order

Then open the draft quotation identified by customer reference **`HARBOR-LOYALTY-01`** and apply that reward so the quotation contains the discount line.

- Do not confirm the quotation
- Do not change the seeded product line
