# Approve a pending time-off request

You are in the Odoo 19 **Time Off** app logged in as **Administrator**.

An employee has submitted a time-off request that needs your approval.

## What to do

1. Go to the **Time Off** app and navigate to the **Managers** section
   (or **Time Off → Managers → Time Off**) to see pending requests.
2. Find the pending request from **Marc Demo** for **Sick Time Off**
   dated **June 9 to June 11, 2026** with description
   **"Medical appointment recovery"**.
3. Open the request and click **Approve** to approve it.

After approval the request should be in **Approved** (Validated) status.

## Rules

- Only approve the request for **Marc Demo** — do **not** modify or
  approve any other requests.
- Do **not** refuse the request.
- Do **not** create any new time-off requests.
- Do **not** delete or cancel the request.
