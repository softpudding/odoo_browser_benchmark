Go to the **Manufacturing** app and open the manufacturing order **`WH/MO/BENCH-WO-01`**.

Carry out this workflow in order:

1. Plan the manufacturing order
2. Start its work order
3. Block the work center with reason **`Equipment Failure`**
4. Resume or unblock the work so the work order can continue
5. Finish the work order
6. Finish the manufacturing order

Leave the manufacturing order fully completed.

## Rules

- Do not cancel the manufacturing order
- Do not create a second manufacturing order
- Do not change the BOM or product quantities
