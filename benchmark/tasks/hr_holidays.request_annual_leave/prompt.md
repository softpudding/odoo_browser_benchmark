# Request an annual leave

You are in the Odoo 19 **Time Off** app logged in as **Administrator**.

You need to submit your own time-off request for an upcoming vacation.

## What to do

1. In the **Time Off** app, click the **New** button to start a new request.
2. Fill in the request:
   - **Time Off Type**: `Paid Time Off`
   - **Dates**: from **July 20, 2026** to **July 22, 2026** (3 days)
   - **Description**: `Family vacation to Iceland`
3. Save the request (it will automatically move to **To Approve** state).

## Rules

- Use the **Paid Time Off** leave type exactly — not Sick Time Off or any
  other type.
- Do **not** approve or validate the request yourself — it should be left
  in the submitted/"To Approve" state.
- Do **not** modify any other existing time-off requests.
- Do **not** delete the request.
