# Refuse a pending time-off request

You are in the Odoo 19 **Time Off** app logged in as **Administrator**.

Employee **Marc Demo** has submitted a time-off request that needs to
be refused because the team cannot cover his shift.

## What to do

1. Open the **Time Off** app and go to **Management → Time Off** (the
   manager approval queue) so you see pending requests.
2. Find the pending request **Unscheduled absence — please refuse**
   from **Marc Demo**.
3. Open the request and click **Refuse** (the statusbar action that
   refuses the leave).
4. The request must move from **To Approve** (`confirm`) to
   **Refused** (`refuse`).

## Rules

- Refuse the **Unscheduled absence — please refuse** request only.
- Do **not** approve or validate any request.
- Do **not** delete the request.
- Do **not** modify any other leave requests.
