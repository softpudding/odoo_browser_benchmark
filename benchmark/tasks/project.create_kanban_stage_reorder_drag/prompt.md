Go to the **Project** app.

Open the project **"Bench Project A"** — this opens the kanban board of its tasks,
grouped by stage. The seeded stages, left-to-right, are:

1. **Triage**
2. **In Progress**
3. **Review**
4. **Done**

You have two things to do, **in this order**:

### 1. Create a new stage called "Backlog Review"

At the right edge of the kanban board (to the right of the last "Done" column)
there is a collapsed **"+"** quick-create column (chevron / "Add column" icon).

- Click it to expand the stage quick-create input.
- Type **Backlog Review** into the stage-name input.
- Confirm (green check button, or press Enter) to create the stage.

Newly-created stages are added at the **end** (right side) of the kanban — so
after this step the columns read: Triage, In Progress, Review, Done, Backlog Review.

### 2. Drag "Backlog Review" to position #2 (before "In Progress")

Reorder the kanban columns by **dragging the "Backlog Review" column to the
left** so that it ends up at position #2 in the board — i.e. immediately to the
right of **Triage** and immediately to the left of **In Progress**.

To drag a column, press and hold on the **"Backlog Review" column title
(header text)** and drag it leftward across the other column headers until the
column snaps between Triage and In Progress, then release.

After the drop the left-to-right order must be:

1. Triage
2. **Backlog Review**
3. In Progress
4. Review
5. Done

The kanban view auto-saves as soon as the drop completes — no explicit Save button.

**Rules:**
- Do **not** rename, fold, archive, or delete any existing stage.
- Do **not** create any task records.
- Do **not** modify any other project.
- The new stage must be scoped to **Bench Project A** (the quick-create button
  already scopes to this project — do not change that).
