Go to the **Sales** app.

Find the confirmed sales order with customer reference **BENCH-COMMIT-01** for customer **"Highfield Consulting"**.

This order needs a delivery date added before it is finalized. You must:

1. **Cancel the order**: click **Cancel Order** (or **Cancel**). The order moves to "Cancelled" state.
2. **Reset to Draft**: click **Reset to Draft**. The order returns to "Draft" / "Quotation" state.
3. Navigate to the **Other Information** tab on the order form.
4. Set the **Delivery Date** field to **05/20/2026**.
5. **Confirm the order**: click **Confirm**.

The final state of the order must be **Sales Order** (confirmed) with Delivery Date set to May 20, 2026.
