Configure one unpublished website product so it becomes purchasable with variants.

1. Open the product named `Field Pack Duffel`.
2. Add the attribute `Bench Size` to the product.
3. Use exactly these two values for that attribute: `Carry-On` and `Weekender`.
4. Publish the product to the website shop.
5. Verify the product is visible on the website shop after publishing.

Rules:
- Do not rename the product.
- Do not add any extra attributes or extra values.
- The product must stay published and must have both size values attached to the same attribute line.
