# Pin a message and post a follow-up in a Discuss channel

You are in the Odoo 19 **Discuss** app logged in as **Administrator**.

A channel already exists with one important message that teammates need to
see pinned, and you owe them an acknowledgement.

## What to do

1. In **Discuss**, open the channel named **#Morning Standups Alpha**.
2. Find the message with exact body:

   ```
   Print queue alert from warehouse B
   ```
3. Pin that message (hover the message, open its action menu, click **Pin**,
   and confirm if a confirmation dialog appears).
4. In the same channel, post a new message with this exact text:

   ```
   Acknowledged - investigating now
   ```

## Rules

- Pin only the one message quoted above — do not pin any other message.
- Do not create a new channel; work inside **Morning Standups Alpha**.
- Do not delete or edit the original message.
- The follow-up message body must match exactly.
