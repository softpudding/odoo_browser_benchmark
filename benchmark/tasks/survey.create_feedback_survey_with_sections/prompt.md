Go to the **Surveys** app and create a new feedback survey with these exact settings.

## Header

- **Survey Title**: `Q1 Workshop Feedback`
- **Description**: `Share your thoughts on the March workshop`
- This is a regular feedback survey — do **not** turn it into an Assessment / Certification.

## Options tab

- **Pagination**: `One page per section`
- **Access Mode**: `Anyone with the link`
- **Survey Time Limit**: enabled, set to **`10`** minutes

## Questions tab

Create exactly **2 sections**, each containing **2 questions**, in this order.

### Section 1 — `Content`

1. **Question**: `How clear was the material?`
   - Type: `Multiple choice: only one answer`
   - Answers: `Very clear`, `Clear`, `Unclear`
2. **Question**: `Rate the pace`
   - Type: `Scale` (use the 1 to 5 numerical scale). If a Scale type is not available, use `Numerical Value` instead.

### Section 2 — `Logistics`

3. **Question**: `Was the venue comfortable?`
   - Type: `Multiple choice: only one answer`
   - Answers: `Yes`, `No`
4. **Question**: `Comments`
   - Type: `Multiple Lines Text Box`

## Save & publish

- **Save** the survey.
- The survey must remain **active** (not archived) so it is ready to share.

## Rules

- Do **not** add extra sections or questions.
- Do **not** mark this as a Certification.
- Do **not** archive the survey.
- Keep the answers list for each multiple-choice question exactly as listed above (no extra/empty options).
