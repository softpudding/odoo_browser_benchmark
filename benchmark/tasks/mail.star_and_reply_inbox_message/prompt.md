# Star and reply to an inbox message

You are in Odoo 19 logged in as **Administrator**.

A colleague named **Bench Coordinator** has sent you a message asking you to
confirm receipt of the Q2 status update. It is waiting in your Discuss
**Inbox**. You need to bookmark (star) it for follow-up and send a short
acknowledgement reply.

## What to do

1. Open the **Discuss** app.
2. Click the **Inbox** entry in the left sidebar.
3. Find the message whose body contains:

   ```
   Please confirm receipt of the Q2 status update.
   ```

   It was authored by **Bench Coordinator**.

4. Hover that message to reveal its action toolbar and click the
   **star / bookmark / Mark as Todo** icon so the message is marked as
   starred for you.

5. Still on that message, click the **Reply** action in the same toolbar
   (the curved arrow icon) to open the reply composer, and post a reply
   with this exact body:

   ```
   Acknowledged - will follow up by Friday.
   ```

   Send it (click the Send button or press Enter).

## Rules

- Star exactly **one** message — the Bench Coordinator one quoted above.
- The reply body must match exactly, including the hyphen and period.
- Do **not** delete or edit the original message.
- Do **not** star any other messages.
