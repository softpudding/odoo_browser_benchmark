Create and publish a new blog post.

1. Open the Blogs app (Website > Blogs, or the top-level "Blogs" menu).
2. Click **New** to create a new blog post.
3. Set the title to `Product Launch Announcement`.
4. Select the blog `Our blog` (this is the default blog shipped with Odoo demo data).
5. Set the subtitle to `Announcing our newest product lineup for Q2.`
6. Save the post.
7. Publish the post (toggle the "Unpublished" / "Published" switch in the top-right of the form, or click the Publish action so the post is publicly visible).

Rules:
- Use the exact title, blog, and subtitle above — spelling and punctuation must match.
- Do not create extra blog posts.
- Do not delete or rename the existing `Our blog` blog.
- The post must end up in the **published** state when you finish.
