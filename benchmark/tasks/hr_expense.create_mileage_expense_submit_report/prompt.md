Create and submit a mileage expense in Odoo Expenses.

1. Open the Expenses app.
2. Create a new expense for employee `Administrator`.
3. Use category `Mileage`.
4. Set the expense title to `Client Visit Mileage`.
5. Set the expense date to `04/14/2026`.
6. Set the total to `128.40`.
7. Save the expense.
8. Submit the expense for approval.

Rules:
- Do not create more than one expense named `Client Visit Mileage`.
- Do not change the employee, title, date, or amount after submission.
- The expense must end in the `Submitted` state.
- Do not approve, post, or refuse the expense.
