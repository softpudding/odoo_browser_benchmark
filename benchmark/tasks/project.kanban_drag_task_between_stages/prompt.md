Go to the **Project** app.

Open the project **"Benchmark Drag Project"**.

The default view is the **Kanban** view, which is organised by task stage columns: **"To Do"**, **"In Progress"**, and **"Done"**.

Find the task card **"Benchmark Card Alpha"** in the **"To Do"** column.

**Drag that task card from the "To Do" column into the "In Progress" column.**

The kanban view auto-saves as soon as the card is dropped in the new column — no explicit save is needed.

**Rules:**
- Do **not** rename the task.
- Do **not** change its deadline or assignee.
- Do **not** modify any other tasks on the board (for example, do not move "Benchmark Card Beta").
- Do **not** use the task form view — you must use drag-and-drop on the kanban card.
