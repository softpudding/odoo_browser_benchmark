Open the **Live Chat** app.

From the Live Chat app, open **Configuration → Canned Responses** (Canned Responses list).

Create a new canned response with these exact values:

- **Shortcut**: `:greet`
- **Substitution**: `Hello! How can I help you today? — Bench Support`

Save the canned response.

**Rules:**
- The shortcut must be exactly `:greet` (starting with a colon).
- The substitution text must match exactly, including the em-dash (`—`) and the trailing `Bench Support`.
- Do not create more than one canned response.
- Do not delete or modify any existing canned response.
