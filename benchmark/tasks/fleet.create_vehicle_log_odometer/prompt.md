# Create a vehicle and log an odometer reading

You are in the Odoo 19 **Fleet** app logged in as **Administrator**.

## Step 1 — Create a vehicle

1. Click **New** to create a new vehicle.
2. Set the **Model** to **Audi** (brand) / a model of your choice, or create
   a new model: type **A4** and select or create it under the **Audi** brand.
3. Set the **License Plate** to **BENCH-FL-01**.
4. Set the **Driver** to **Mitchell Admin**.
5. Set the **Tags** or leave them empty.
6. **Save** the vehicle.

## Step 2 — Log an odometer reading

1. On the vehicle form, find the **Odometer** section or the odometer
   smart button.
2. Click on it to open the odometer log.
3. Click **New** to add a new odometer entry.
4. Set the **Odometer Value** to **15200**.
5. Set the **Date** to **06/01/2026**.
6. **Save** the odometer entry.

## Rules

- The license plate must be exactly **BENCH-FL-01**.
- The odometer value must be exactly **15200**.
- Do **not** delete any existing vehicles.
- Do **not** create more than one vehicle.
