# Create And Post The June Invoice

Create a new customer invoice in Accounting for **Northwind Advisory**.

1. Go to **Customer Invoices** and click **New**.
2. Set **Customer** to `Northwind Advisory`.
3. Set **Invoice Date** to `June 10, 2026`.
4. Set **Customer Reference** to `NWA-AR-220`.
5. Add these invoice lines:
   - `Strategic Workshop` with quantity `2` and unit price `1200.00`
   - `Support Retainer` with quantity `1` and unit price `850.00`
6. Click **Confirm** to post the invoice.

## Rules

- Create exactly one invoice.
- Do not add any extra invoice lines.
- Do not register a payment.
- Do not edit any other invoices.
