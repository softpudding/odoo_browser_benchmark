# Bulk-enrich three CRM leads from the Leads list view

You are in the Odoo 19 **CRM** app logged in as **Administrator**.

Marketing just imported five new leads and asked you to run the
**Enrich Contact(s)** server action on the three that still need company
info. The other two are off-limits — one has already been enriched and
one is explicitly marked as do-not-enrich.

| Reference          | Name                          | Email                         | Notes                        |
|--------------------|-------------------------------|-------------------------------|------------------------------|
| BENCH-ENRICH-001   | Bench Enrich Target Alpha     | alpha.bench@gmail.com         | **Must be enriched**         |
| BENCH-ENRICH-002   | Bench Enrich Target Bravo     | bravo.bench@gmail.com         | **Must be enriched**         |
| BENCH-ENRICH-003   | Bench Enrich Target Charlie   | charlie.bench@gmail.com       | **Must be enriched**         |
| BENCH-ENRICH-DONE  | Bench Enrich Already Delta    | delta.bench@gmail.com         | **Already enriched — skip**  |
| BENCH-ENRICH-SKIP  | Bench Enrich Manual Echo      | echo.bench@gmail.com          | **Do NOT enrich — skip**     |

## What to do

1. From the CRM top menu, open **Leads → Leads** (the Leads list, NOT
   the Pipeline / Opportunities board).
2. If the page opens in Kanban view, click the **List** view button
   (the icon with horizontal lines) in the top-right of the view
   switcher so each row shows a checkbox in its leftmost cell.
3. **Clear any default filters** (remove the `Unassigned` chip or any
   other search facet so all five "Bench Enrich" leads are visible).
   You may type `Bench Enrich` in the search box and press Enter to
   narrow the list.
4. Tick the row checkboxes on **exactly these three leads** — their
   names in the Opportunity column:
   - `Bench Enrich Target Alpha`
   - `Bench Enrich Target Bravo`
   - `Bench Enrich Target Charlie`

   Do NOT tick `Bench Enrich Already Delta` (already enriched) or
   `Bench Enrich Manual Echo` (marked do-not-enrich).
5. With the three rows selected, open the **Actions** menu (the gear /
   ⚙ / "Actions" dropdown that appears in the control panel once at
   least one row is selected) and click **Enrich**.
6. Wait for the action to finish. A no-credit notification toast may
   briefly appear — that is expected and OK to dismiss. The action
   records its outcome directly in the chatter of each selected lead.

## Expected end state

- Each of the three target leads (`BENCH-ENRICH-001`, `-002`, `-003`)
  has `iap_enrich_done = True` AND a new chatter note whose body
  mentions **"No company data found"** (the service's no-match / no-
  credit template — the seeded emails are all on generic providers
  like `@gmail.com`, so the enrichment short-circuits without
  consuming any credit).
- The two distractor leads (`BENCH-ENRICH-DONE`, `BENCH-ENRICH-SKIP`)
  are unchanged: their `iap_enrich_done` flag keeps its pre-seed
  value, and no new "No company data found" chatter note is added to
  them during this run.

## Rules

- Use the **Actions menu** (multi-select list action), not the
  per-record **Enrich** button inside a single lead's form header.
  Triggering the form-header button on each lead one-by-one is a
  failure mode — you must select all three in the list and run one
  bulk action.
- Select **exactly 3** leads — no more, no fewer. Including
  `Bench Enrich Already Delta` or `Bench Enrich Manual Echo` in the
  selection counts as a failure.
- Do not archive, delete, rename, or convert any lead.
- Do not create any new lead.
- Do not manually post a chatter note that says "enriched" — the
  note must be the one auto-generated by the Enrich server action
  itself.
