# Raise a ticket's seat limit on an event

You are in the Odoo 19 **Events** app logged in as **Administrator**.

The event **Autumn AI Summit** has a **General Admission** ticket with
the seat limit set to **100**. Marketing has secured a larger venue
and you need to bump the seat limit to **250**.

## What to do

1. Open the **Events** app and open the event **Autumn AI Summit**.
2. Go to the **Tickets** tab.
3. Find the row for the **General Admission** ticket (current seats
   max = 100).
4. Update **Maximum Attendees** to **250**.
5. Save the event.

## Rules

- Update only the **General Admission** ticket — do not touch other
  tickets or event fields.
- The new **seats_max** must be exactly **250**.
- Do **not** create new tickets.
- Do **not** delete the General Admission ticket.
