Add a graded quiz lesson to an existing eLearning course.

Background: A published course named `Bench Onboarding Course` already exists in
the eLearning app and currently has one lesson, `Welcome Video`. Leave that
existing video lesson untouched.

Steps:

1. Open the eLearning app and go to the `Bench Onboarding Course`.
2. Open the course content list and add a new content item with these fields:
   - Title: `Chapter 1 Quiz`
   - Category / Type: `Quiz`
   - Duration / Completion time: `5` minutes
3. Save the new quiz lesson.
4. Open the new quiz lesson and switch to its `Questions` tab. Add exactly the
   following three questions, each with three answer options. Mark exactly one
   answer per question as the correct answer (the one shown first below):

   Question 1: `What is the primary color of the Bench logo?`
   - `Blue`  (correct)
   - `Red`
   - `Green`

   Question 2: `How often do we stand up?`
   - `Daily`  (correct)
   - `Weekly`
   - `Never`

   Question 3: `Which team owns shared infra?`
   - `Platform`  (correct)
   - `Product`
   - `Growth`

5. Publish the new `Chapter 1 Quiz` lesson so it is visible on the course
   (the lesson must be published, not just saved as a draft).

Rules:
- Use the exact question and answer texts above.
- Each of the three questions must have exactly three answer options.
- Each question must have exactly one correct answer; it must be the one
  marked `(correct)` above (Blue, Daily, Platform).
- Do not modify the existing `Welcome Video` lesson and do not add any
  additional questions, answers, or lessons.
