Go to the **Point of Sale** app and open the register **`Bench Restaurant`** (accept the default opening cash of 0 if a dialog appears).

This is a restaurant-style POS. When the register opens you should see the **floor plan** with table **`T1`** on the floor called `Main Floor`.

1. Click table **`T1`** on the floor plan so the register opens an order attached to that table.
2. Add **`Starter Salad`** (€15) to the order — quantity **1**.
3. Click the **Course** button on the action pad. This wraps the Starter Salad into **Course 1** and selects a new empty **Course 2** for subsequent items.
4. Add **`Main Steak`** (€20) to the order — quantity **1**. Because Course 2 is selected, this line goes into Course 2.
5. Click the **Send** / **Order** button on the right side of the action pad (the big primary button that shows the category-count summary — NOT the grey `Payment` button). This sends the order to the kitchen and **marks Course 1 as fired (Ready)**. After clicking, Course 1 should display the **`Fired`** badge.

Do NOT proceed to payment. Do NOT close the POS session. Leave the order open, linked to table `T1`, with both lines and Course 1 fired.

## Rules

- Use the table `T1` that is already on the floor plan — do NOT create a new table or a new floating order.
- Do NOT change the unit prices (Starter Salad must stay €15, Main Steak must stay €20).
- Do NOT add any other products.
- Do NOT pay or validate — leave the order in draft.
- Do NOT close the POS session.
- The **Send** button appears in place of the `Payment` button once there are unsent lines; use it to fire Course 1.
