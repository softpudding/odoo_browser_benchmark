Sell the seeded event product and complete the attendee registration.

1. Open the Sales app and create a new quotation for customer `Northwind Workshops`.
2. Add product `Enablement Seat Product` to the order line.
3. In the event configurator dialog, choose:
   - Event: `Partner Enablement Day`
   - Event Ticket: `Workshop Seat`
4. Confirm the quotation.
5. In the Event Registrations dialog, fill the attendee row with:
   - Name: `Jordan Rivera`
   - Email: `jordan.rivera@example.com`
6. Click `Create/Update registrations`.

Rules:
- Do not create or edit event tickets.
- Do not create an invoice.
- Do not create more than one sale order or more than one registration.
- Do not change the product price or quantity.
