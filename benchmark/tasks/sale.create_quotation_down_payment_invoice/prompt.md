Go to the **Sales** app.

Create a new quotation with the following details:

1. Set **Customer** to **Ridgeline Automation**.
2. Set **Customer Reference** to **`RA-DP-2026`**.
3. Set **Expiration** to **06/15/2026** (June 15, 2026).
4. Add the following product lines:
   - **Modular Conveyor Belt** -- Quantity: **5**, Unit Price: **$1,200.00**
   - **Safety Light Curtain** -- Quantity: **10**, Unit Price: **$350.00**
5. Click **Confirm** to confirm the quotation (turning it into a sales order).

Now create a down payment invoice:

6. Click **Create Invoice**.
7. In the invoice creation wizard, select **Down payment (percentage)** -- do **NOT** use "Regular invoice".
8. Set the down payment percentage to **30%**.
9. Click **Create Draft** in the wizard.

Finally, confirm the generated invoice:

10. On the resulting draft invoice, set **Invoice Date** to **06/01/2026** (June 1, 2026).
11. Click **Confirm** to post the invoice.

**Rules:**
- You must select "Down payment (percentage)" in the wizard, NOT "Regular invoice"
- Do NOT change the product prices or quantities from the values above
- Do NOT create more than one invoice
- Do NOT register a payment
