Go to the **Inventory** app.

Open **Operations -> Inventory Adjustments**.

Find the inventory adjustment line for product **`Bench Cycle Rotor`** at location **`WH/Cycle Bin`**.
There is another `Bench Cycle Rotor` line in a different location that is a distractor.

On the **WH/Cycle Bin** line only:
- set the **Counted Quantity** to `11`
- set the **Counted Date** to `05/15/2026`
- apply the inventory adjustment for that line

Rules:
- Update only the `WH/Cycle Bin` line.
- Do not modify the `WH/Stock` line for the same product.
- Do not create a new adjustment line.
- Leave the product name unchanged.
