Open the Invoicing (Accounting) app. There are two draft customer invoices for similar customers.

Edit **only** the draft invoice whose source document is `VAT-302`.

That invoice should be posted only after the correct customer record has a Tax ID.

Your job:

1. Open the draft invoice for `VAT-302`.
2. On the **Invoice Lines** tab, scroll down and read the VAT value written in **Terms and Conditions**.
3. Open the customer record from that invoice and set the customer's **Tax ID** to that exact VAT value.
4. Return to the same invoice using the application breadcrumbs.
5. Set **Customer Reference** to `VAT-302-CLEAR`.
6. Post the invoice.

Do not edit the other customer or the other draft invoice.
