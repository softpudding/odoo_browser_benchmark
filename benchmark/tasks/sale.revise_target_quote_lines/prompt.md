Go to the Sales app. There are several draft quotations for customer **Aurora Interiors**.

Edit **only** the quotation whose customer reference is `OPS-042`.
If a default **My Quotations** filter is active, clear it first so all quotations are visible.

For that quotation:

1. Open the quotation and verify the `OPS-042` customer reference under **Other Info** if needed.
2. From the Sales app's **Products** menu, open each product on the quotation and read its **Sales Description** field on the product form.
3. The Sales Description tells you the exact line description to use and the discount to apply.
   The quotation already supports per-line discounts, so do **not** change any global Sales settings.
4. Return to the quotation and update all three order lines so that:
   - the line description matches the product's Sales Description instruction
   - the discount matches the instruction
5. Open the **Other Info** tab and set **Payment Terms** to `15 Days`.
6. Save the quotation, but do **not** confirm it.

Do not change any other quotation.
