Go to the **Project** app.

Open the project **Atlas Support Rollout** and find the standalone task
**Vendor readiness checklist**.

Update that task as follows:

1. Use the task actions to convert it into a **sub-task**.
2. In the conversion dialog, set **Parent Task** to **Launch coordination**.
3. Save the conversion if needed.

**Rules:**
- Do not create a new task
- Do not change the parent task **Launch coordination**
- Do not convert any other task into a sub-task
- Do not change the project settings
