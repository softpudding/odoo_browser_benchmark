Go to the **Inventory** app. Navigate to **Operations > Transfers**.

Find the receipt (incoming transfer) with reference **"BENCH-RCV-01"**.

1. Open the transfer.
2. For each product line, set the **Done** quantity (**Quantity** column in
   the Detailed Operations tab, or the **Done** column in the Operations tab)
   to match the **Demand** quantity:
   - **Steel Bracket 12"**: set Done to **20**
   - **Copper Wire 100m**: set Done to **10**
3. Click **Validate** to complete the receipt.
4. If a confirmation dialog appears, click **Apply** or **Ok** to confirm.

**Rules:**
- Do not create any new transfers
- Do not change the source or destination locations
- Do not modify the demand quantities
- Only set Done quantities equal to the demand
