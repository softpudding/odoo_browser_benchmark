Go to the **Sales** app.

If you first land on the public website, click **Sign in** and log in before continuing.

Find the draft quotation with customer reference **S-BENCH-OPT-001** for customer **"Bench Optional Co"** and open it.

The quotation already contains one line for the product **"Bench Hardware Kit"**. **Do not modify** that existing line.

You must **add a new order line** to this same quotation:

1. In the order lines table, click **"Add a product"**.
2. In the product autocomplete, search for and select **"Bench Service Bundle"**.
3. On that **same new line**, set **Quantity** to **2**.
4. On that **same new line**, set the per-line **Discount** field to **10** (10%).
5. Click **Save** to save the quotation.

**Rules:**
- Keep the quotation in **draft** state — do **not** confirm it.
- Do **not** change the existing Bench Hardware Kit line (quantity, price, discount).
- Do **not** change quotation header fields (customer, customer reference, salesperson, payment terms).
- Do **not** delete any line.
- The discount column on order lines is already enabled — there is no need to change global Sales settings.
