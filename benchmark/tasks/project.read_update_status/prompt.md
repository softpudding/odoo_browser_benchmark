Go to the Project app. There is a project called "Q2 Launch".

This project has several tasks across different stages. The kanban view may have an "Open" filter active by default — **remove this filter** to see all tasks including completed ones. You can also switch to the list view for a clearer overview.

Your job:
1. Count the total number of tasks in this project, and how many are in the "Done" stage.
2. Open the project settings: click the "⋮" (three-dot/vertical ellipsis) menu next to the project name in the breadcrumb, then select "Settings".
3. In the project settings form, find the **Description** field and type exactly: "X of Y tasks complete" — where X is the number of Done tasks and Y is the total number of tasks.

For example, if 2 out of 5 tasks are Done, write exactly: `2 of 5 tasks complete`

4. Save the settings. Do NOT modify, move, create, or delete any tasks.
