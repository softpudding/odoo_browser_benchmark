Go to the Project app. There is a project called "Q2 Launch".

This project has several tasks. Some tasks are in the "Done" stage and some are not.

Your job:
1. First, look at all tasks in this project and count how many are in the "Done" stage.
2. Then go to the project settings (click the three-dot menu or the project name settings) and update the project **Description** field to say exactly: "X of Y tasks complete" where X is the number of Done tasks and Y is the total number of tasks.

For example, if 3 out of 5 tasks are Done, write "3 of 5 tasks complete".

Save the project settings after updating the description.
