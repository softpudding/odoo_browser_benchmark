Open the published product **`Bench Gallery Mug`** in the backend and add an extra image to its media gallery.

Steps:

1. From the **Products** page (`/odoo/inventory/products`), open the product `Bench Gallery Mug`.
2. On the product form, open the **Sales** tab. Inside it you will see the **eCommerce Media** section (a media kanban grid with an **Add Media** tile).
3. Click **Add Media** to create a new `product.image` entry. Upload any small image file and set the image's **Name** to `Bench Side View`.
4. **Save** the product form so the new image is persisted.

**Rules:**
- Do not unpublish the product.
- Do not rename, delete, or change the main product image.
- Do not modify the price, description, taxes, or any other field on the product.
- Create exactly one new media entry named `Bench Side View`; do not add any other extra images.
