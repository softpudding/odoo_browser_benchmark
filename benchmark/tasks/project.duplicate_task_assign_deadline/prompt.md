# Duplicate The Task For APAC

Use the Project app to duplicate a task and update the copy.

1. Open project `Launch Enablement Board`.
2. Open task `Prepare webinar outline`.
3. Use the **Action** menu to **Duplicate** the task.
4. On the duplicated task:
   - rename it to `Prepare webinar outline - APAC`
   - set **Deadline** to `June 24, 2026`
   - move it to **In Progress**
5. Save the duplicated task.

## Rules

- Duplicate the task instead of editing the original.
- Do not edit `Prepare sales deck`.
- Leave the original `Prepare webinar outline` task in **To Do** with no deadline.
