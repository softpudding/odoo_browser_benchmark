# Create A New Lead And Schedule Follow-Up

Create a new CRM lead and schedule a follow-up call.

1. Go to the **CRM** app.
2. If needed, switch to the **Leads** view.
3. Create a new lead named `Apex Warehouse Expansion`.
4. Set these fields:
   - **Contact Name**: `Jordan Pike`
   - **Email**: `jordan.pike@apexwarehouse.com`
   - **Expected Revenue**: `48000`
   - **Priority**: `2 stars`
5. Save the lead.
6. Schedule a **Call** activity with:
   - **Due Date**: `June 15, 2026`
   - **Summary**: `Qualify warehouse rollout`

## Rules

- Create a lead, not an opportunity.
- Do not create a quotation.
- Do not modify `Apex Warehouse Renewal`.
