Go to the **Surveys** app and create a new survey with these exact settings:

- **Survey Title**: `Dock Safety Branching Quiz`
- **Survey Type**: `Custom` (the default — do **not** change it to "Survey")
- **Pagination**: `One page with all the questions`
- **Scoring**: enabled as a quiz
- **Access**: public share link

Add these questions in order:

1. **Question**: `Which dock zone requires extra clearance tonight?`
   - Type: single choice
   - Answers:
     - `Zone A`
     - `Zone B`
   - Mark `Zone B` as the correct answer

2. **Question**: `Why is Zone B restricted tonight?`
   - Type: text box
   - Make this question conditional so it only appears when `Zone B` is selected in the first question

Save the survey and leave it ready to share publicly.
