# Confirm The Updated Quotation

Update and confirm quotation `S-QUOTE-VAL-01`.

1. Go to the **Sales** app.
2. Open quotation `S-QUOTE-VAL-01` for `Cedar Grove Studio`.
3. Set **Salesperson** to `Marc Demo`.
4. Set **Expiration** to `June 25, 2026`.
5. Set **Customer Reference** to `CGS-JUNE`.
6. Click **Confirm**.

## Rules

- Do not change any product line quantities or prices.
- Do not edit quotation `S-QUOTE-VAL-02`.
- Only confirm the target quotation after updating those three fields.
