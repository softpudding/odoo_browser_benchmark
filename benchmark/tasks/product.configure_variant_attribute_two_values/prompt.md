Configure variants on an existing product by adding a `Size` attribute with three values. Saving the product must auto-generate the three variants.

1. Open the product named `Bench Variant Shirt`.
2. Switch to the `Attributes & Variants` tab on the product form.
3. Add a new attribute line. Set:
   - Attribute: `Size` (create it inline if it does not already exist).
   - Values: `Small`, `Medium`, `Large` (create each value inline if it does not already exist).
4. Save the product. The three variants will be generated automatically.

Rules:
- Do not rename the product.
- Use exactly the attribute name `Size` and the three value names `Small`, `Medium`, `Large` (case-sensitive, singular, in that order).
- Do not add any other attribute lines, attributes, or values.
- The product must remain saved with those three values attached to a single `Size` attribute line.
