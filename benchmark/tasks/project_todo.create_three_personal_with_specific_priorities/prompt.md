Open the **To-do** app.

Create the following three personal to-do notes (one at a time), and save each:

1. **Plan Sprint** — set the priority by clicking **only the FIRST priority star** so it lights up (this is the **Medium priority** level — exactly one star filled, the second star unfilled).
2. **Write Docs** — leave the priority at the default (no star filled).
3. **Refactor CSS** — leave the priority at the default (no star filled).

You can use the kanban "+" / "New" entry point or the form view. After typing the title for **Plan Sprint**, click the first of the two priority stars (so one star is on, one is off) and save the record. For the other two notes, do not touch the priority widget at all — just type the title and save.

## Rules

- Use these exact titles, with the same capitalization
- Do **not** rename, archive, or delete any of the three notes after creating them
- Do **not** add tags, descriptions, deadlines, or extra assignees
- Only **Plan Sprint** should end up with one filled star (Medium priority); **Write Docs** and **Refactor CSS** must have zero filled stars (default priority)
- Do **NOT** click the second star on Plan Sprint — that would set it to High priority, which is wrong
- Do not modify any pre-existing notes
