Go to the **Project** app.

Find the project **"Bench Template Project"** on the main Project dashboard. It currently has **3 tasks**: "Setup", "Build", and "Review".

**Duplicate this project**, so you end up with a second project that is a complete copy of the template (with all three tasks copied as well).

**How to duplicate:**
- On the project's kanban card, open the **3-dot ("vertical ellipsis") menu** and click **"Duplicate"**, OR
- Open the project and use the **Actions (cog) menu > Duplicate** from the project form view.

**Name the copy exactly:**

```
Bench Template Project (Copy)
```

If the duplicate action offers a name prompt, type that name. If the duplicate lands with a default name like "Bench Template Project (copy)" in lowercase, **rename it** so the final name matches exactly (capital "C" in "Copy").

**Rules:**
- Do **not** modify, rename, or delete the original "Bench Template Project".
- Do **not** delete or rename any of the original tasks.
- The new project **must contain all 3 tasks** ("Setup", "Build", "Review"). Do not add or remove tasks from the copy.
- Save any changes before leaving the form.
