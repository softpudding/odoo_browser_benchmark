# Cancel The Paused RFQ

Cancel the draft RFQ `P-RFQ-CANCEL-01` in Purchase.

1. Open RFQ `P-RFQ-CANCEL-01`.
2. In the chatter, click **Log note**.
3. Post this exact note:
   `Vendor asked us to pause this request until next quarter.`
4. Click **Cancel** on the RFQ.

## Rules

- Only cancel `P-RFQ-CANCEL-01`.
- Use **Log note**, not **Send message**.
- Do not change or cancel `P-RFQ-CANCEL-02`.
