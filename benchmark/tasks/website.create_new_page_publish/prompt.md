Open the **Website** app.

Create a brand new website page from scratch:

1. In the top bar of the Website backend, click the **+ New** button (or the
   equivalent "New" action) and choose **Page**.
2. In the **New Page** dialog:
   - Enter the page **Name**: `Bench New Page`
   - Choose the **Blank Page** template (not one of the pre-designed
     templates).
   - Click **Create** to open the page in the website editor.
3. The page URL should be `/bench-new-page` (Odoo will slugify the name into
   this URL automatically). If it is not, adjust the URL to
   `/bench-new-page`.

You should now be on the new page in the website editor. Add content:

- Add an **H1 heading** to the page body with the exact text
  `Welcome to Bench`. You can drop a Text or Heading block from the editor
  sidebar and type the text, or edit an existing heading placeholder and
  change it to `Welcome to Bench`.
- Click **Save** in the editor to persist the change.

Publish the page:

- Toggle the page's status from **Unpublished** to **Published** using the
  **Unpublished / Published** switch in the editor top bar (or from the
  Pages list if needed).

**Rules:**
- The new page must be named exactly `Bench New Page`.
- The URL must be exactly `/bench-new-page`.
- The page's rendered content must contain a heading with the text
  `Welcome to Bench`.
- The page must end up **Published**.
- Do not create any other website pages, and do not delete existing pages.
