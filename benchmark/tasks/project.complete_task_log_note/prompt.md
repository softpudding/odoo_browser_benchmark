Go to the **Project** app and open the project named **Omega Platform Launch**.

Find the task named **"Write API integration spec"** in the **In Progress** stage.

Complete the following two actions:

1. **Move the task to the Done stage** by dragging it to the Done column
   or using the stage selector at the top of the task form. The stage
   should change to **Done**.

2. **Post an internal log note** in the task's chatter. Click
   **"Log note"** (not "Send message") and enter the following text
   exactly:

   > Spec completed and reviewed by the backend team. Ready for handoff.

   Then click **Add** to post the note.

**Rules:**
- You must use "Log note" — do NOT use "Send message"
- The note text must match exactly (spelling and punctuation)
- Do not assign the task to anyone
- Do not change the task deadline or description
- Do not modify any other tasks in the project
