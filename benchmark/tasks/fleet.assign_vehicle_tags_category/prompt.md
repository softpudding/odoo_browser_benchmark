Assign tags and a category to an existing fleet vehicle.

1. Open the **Fleet** app.
2. In **Vehicles**, open the vehicle **Toyota/Benchmark Tag Vehicle/TAG-001**
   (license plate `TAG-001`).
3. In the **Tags** field (many2many tags widget), add the tags:
   - `Executive`
   - `Sales Team`
4. In the **Category** field (many2one selector), set the category to:
   - `Company Cars`
5. Save the vehicle form.

**Rules:**
- Do not modify the vehicle's model, license plate, driver, or any other field.
- Do not create new tags or categories — the ones you need already exist.
- Do not remove any existing tag from the vehicle.
- The distractor tag `Reserve` must NOT be added.
- The distractor category `Pool Cars` must NOT be selected.
